# Other collections

Larger bodies of rules and rule-reasoning data kept elsewhere. They are listed, not copied: each
has its own licence and terms, so check the source before converting any of it into this
repository, and record its licence and attribution in the converted file.

| Collection | What it holds | Fit for this repository |
| --- | --- | --- |
| [ProofWriter](https://allenai.org/data/proofwriter) and [RuleTaker](https://allenai.org/data/ruletaker) (Allen Institute for AI) | Generated rule sets in English with facts, questions and proofs up to five steps deep, in closed-world and open-world versions | The closest match: the closed-world version uses the same negation as the engine here |
| [OpenFisca](https://openfisca.org) | Tax and benefit law written as code for several countries | Real-world rules at scale; a converter would need to handle numbers and dates |
| [Catala](https://catala-lang.org) | A language for writing law as code, with examples from tax codes | As above |
| [HL7 Arden Syntax](https://www.hl7.org/) and [CQL](https://cql.hl7.org/) libraries | Clinical decision rules | Real rules with real stakes; heavy syntax |
| [CLIPS](https://www.clipsrules.net/) and [Drools](https://www.drools.org/) examples | Example rule bases shipped with the two best-known rule engines | Small, canonical, easy to convert |
| [UCI Car Evaluation](https://archive.ics.uci.edu/dataset/19/car+evaluation) | Data generated from a hierarchical decision model built with experts | Tests whether a model can recover rules from examples |
| OpenCyc | A large common-sense knowledge base; the project ended in 2017, copies remain | A knowledge base rather than an expert system |
